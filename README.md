# brev.ly — Rocketseat Postgraduate Challenge

This project was created for RocketSeat's Postgraduate Program as a way to solidify my learning.  
The main goal is to build a URL shortener app from scratch, covering frontend, backend, and DevOps—all in one place!

## Main Features

- Shorten long URLs and generate shareable links
- User-friendly web interface (frontend)
- REST API for link creation and management (backend)
- Basic authentication and link analytics
- Containerized deployment and configuration with DevOps best practices

## Technologies Used

- React.js / Vite / Tailwind (Frontend)
- Node.js / Express (Backend)
- Docker, CI/CD tools (DevOps)
- AWS (optional cloud deployment)

## Getting Started

1. Clone this repository
2. Install dependencies in both frontend and backend
3. Start development servers
   - Frontend: `npm run dev` in `/web`
   - Backend: `npm run dev` in `/server`
4. Access the app via local URL
